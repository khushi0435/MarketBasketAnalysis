# 🛒 Market Basket Analysis

## 📌 About the Project
Market Basket Analysis is a data mining project that identifies relationships between products purchased by customers. It helps businesses understand customer buying patterns and discover which products are frequently purchased together.

The project uses the **Apriori Algorithm** and **Association Rule Mining** to find frequent itemsets and generate product association rules.

## 🎯 Objectives
- Analyze customer purchasing patterns.
- Identify frequently purchased products.
- Discover relationships between different products.
- Generate association rules using support, confidence, and lift.
- Present insights through an interactive dashboard.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Data Analysis:** Pandas
- **Data Visualization:** Matplotlib
- **Data Mining:** MLxtend
- **Web Dashboard:** Streamlit
- **Dataset:** Groceries Dataset

## ⚙️ Features
- Data cleaning and preprocessing
- Product frequency analysis
- Frequent itemset mining using the Apriori Algorithm
- Association rule generation
- Interactive dashboard
- Product charts and tables
- Downloadable analysis results

## 📊 Key Concepts
- **Support:** Measures how frequently an itemset appears in transactions.
- **Confidence:** Measures how often the consequent occurs when the antecedent occurs.
- **Lift:** Measures the strength of an association between products compared with their independent occurrence.

## 💻 Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/khushi0435/MarketBasketAnalysis.git
   ```

2. Open the project folder:

   ```bash
   cd MarketBasketAnalysis
   ```

3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Streamlit application:

   ```bash
   streamlit run app.py
   ```
